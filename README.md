⏳ TIMEBLOCKS - Cybernetic Focus Dial


TIMEBLOCKS is a web-based productivity and time-management application designed to help users achieve deep focus using time-blocking techniques. Wrapped in a sleek, cyberpunk-inspired interface with lo-fi ambient visuals, it turns productivity into a focused, gamified experience.

✨ Features
🕒 3D Clock Interface: A stunning, interactive 3D analog clock face serving as the central hub for your focus sessions.

📚 Study Blocks: Create, manage, and execute focused study or work sessions (Timeboxing).

🔥 Streak Tracker: Stay motivated by building daily streaks. (Current display shows a 0d Streak, time to get started!).

📅 Calendar Grid: Visualize your scheduled blocks and track your productivity over time.

🌧️ Ambient Aesthetics: Features a beautiful, blurred rainy window background with bokeh lights to induce a calm, lo-fi study environment.

⛶ Full-Screen Mode: Distraction-free viewing with a single click.

🔊 Audio Controls: Integrated sound toggle for ambient noise or timer alerts.

🖥️ Interface Overview
Top Navigation Bar: Switch effortlessly between the 3D Clock, Study Blocks, Streak Tracker, and Calendar Grid.

Status Indicator (Top Left): Displays your current session status. In the screenshot, it reads STATUS: No active block.

System Clock (Top Right): Shows the current digital time (12:06:13 AM) alongside your streak counter and audio/reset controls.

Main Canvas: Houses the large, highly visible analog clock with a distinct pink second hand for precise tracking.

bash

Navigate to the project directory:

bash
cd timeblocks
Install dependencies:

bash
npm install
Start the development server:

bash
npm run dev
Open your browser and navigate to http://localhost:3000/

🎮 How to Use
Set a Block: Click on the "Study Blocks" tab to define your current task and duration.

Focus: Once a block is active, return to the "3D Clock" to monitor your time. The STATUS indicator will update to show your active block.

Build your Streak: Complete your daily goals to increment the flame counter in the top right.

Review: Check the "Calendar Grid" to see your historical focus data.

🎨 Design Philosophy
TIMEBLOCKS aims to reduce the anxiety of traditional timers by combining functional time-tracking with a relaxing, immersive visual environment. The "Cybernetic" theme aims to make studying feel like a futuristic, rewarding mission rather than a chore.
